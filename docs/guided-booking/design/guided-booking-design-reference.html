Design reference · v1 · 20 Nov 2026

Guided walkthrough booking

Visual and interaction reference for the spec in SPEC-conversational-walkthrough-booking.md. Tokens mirror the website's src/styles/tokens.css and follow docs/COLOR_SYSTEM.md: coral only for action and selection, cream for the visitor's own words (the "human moment"), olive for trust and privacy, caramel for progress, muted eyebrows. Brand mark and wordmark are the current assets from public/brand/.

Copy is English reference copy; every string ships through the locale pipeline. Frames are static mockups at real sizes (1280 desktop, 390 phone). The last section is a clickable prototype using the same styles.

1 · Design principles

PrincipleWhat it means on screen
Editorial, not chatbotSundae speaks in typography, not in bubbles. Its first line is set in Fraunces like a page headline; later lines are plain body text on the panel. Only the visitor's answers sit in bubbles - cream pills, the warm "human moment" surface.
One decision at a timeThe answer area holds exactly one input or one set of choices. Nothing else competes for attention; the log scrolls above it.
Coral means "act"Coral appears only on the send button, selected choices, the focus ring and the final primary action. Progress uses caramel; trust and privacy use olive.
Honest and fastLabelled "Guided booking". Typing indicator never longer than 400 ms, none with reduced motion. No human names, avatars or fake delays.
Always reversibleEvery answer can be edited, the classic form is one tap away, and progress survives a refresh.
